# Pocket для Windows — проверка за 5 минут

Установщик: `Pocket-Setup-1.0.0.exe` (без подписи). Нужны: Windows 10/11, пароль от Pocket, интернет.
Отмечай пункты галочкой. Если что-то не так — заведите issue с номером пункта и скриншотом.

Контрольная сумма: в PowerShell `Get-FileHash .\Pocket-Setup-1.0.0.exe` — значение должно совпасть
с файлом `.sha256` рядом с установщиком в релизе.

## 1. Установка и первый запуск (1 мин)
- [ ] 1.1. Запусти `Pocket-Setup-1.0.0.exe`. Windows SmartScreen скажет «Windows защитила компьютер» — это из-за отсутствия подписи: «Подробнее» → «Выполнить в любом случае».
- [ ] 1.2. Установка проходит сама (без вопросов), Pocket запускается. Рядом с часами появился значок Pocket (фиолетовый квадрат с «P» и золотой монетой). Если не видно — он может быть в «скрытых значках» (стрелка ^): перетащи его на панель.
- [ ] 1.3. Над значком открылось маленькое окно «Вход в Pocket». Если `.exe` собран без адреса сервера — сначала поле «Адрес сервера» (например `https://pocket.example.com`), затем поле «Пароль».

## 2. Вход (30 с)
- [ ] 2.1. Введи **неверный** пароль, Enter → под полем «Неверный пароль». Окно не закрылось.
- [ ] 2.2. Щёлкни по рабочему столу — окно входа **не** прячется (так задумано).
- [ ] 2.3. Введи правильный пароль, Enter → открывается окно быстрого ввода. Больше пароль не спросит.
- [ ] 2.4. В вебе https://pocket.example.com → Настройки → Вход и устройства: появилось устройство с именем этого ПК.

## 3. Окно у трея (1 мин)
- [ ] 3.1. Щелчок по значку в трее — окно прячется; ещё щелчок — появляется **у значка**, над панелью задач, не перекрывая её. Курсор сразу в поле «На что потратил деньги?».
- [ ] 3.2. Esc (поле пустое) — окно прячется. Открой меню ⋯ и нажми Esc — закрывается только меню, окно остаётся; второй Esc прячет окно. Напиши в поле что-нибудь и нажми Esc — поле очищается, окно остаётся; второй Esc прячет.
- [ ] 3.3. Щёлкни в другое окно (браузер) — Pocket прячется сам.
- [ ] 3.4. Правый щелчок по значку → меню: «Открыть», «Полная панель», «Настройки», «Выход». «Открыть» показывает окно.
- [ ] 3.5. *(если есть второй монитор)* перенеси курсор на второй монитор и нажми Ctrl+Alt+Space — окно открывается на этом мониторе, целиком на экране, нормального размера (не мелкое и не огромное, даже если масштаб мониторов разный — 100 % и 150 %).
- [ ] 3.6. *(по желанию)* Параметры Windows → Персонализация → Панель задач → расположение сверху/слева (Win10) или «Автоматически скрывать» (Win11): окно всё равно появляется у трея и целиком на экране.

## 4. Горячая клавиша (1 мин)
- [ ] 4.1. Открой любую программу (например, браузер) и нажми **Ctrl+Alt+Space** — Pocket появляется поверх, можно сразу печатать.
- [ ] 4.2. Нажми Ctrl+Alt+Space ещё раз — окно прячется.
- [ ] 4.3. Меню трея → «Настройки» → «Горячая клавиша» → «Изменить» → нажми, например, Ctrl+Alt+K → «Сохранено: Ctrl + Alt + K». Теперь окно открывается по Ctrl+Alt+K, а Ctrl+Alt+Space больше не работает.
- [ ] 4.4. Попробуй назначить сочетание, занятое другой программой (например, то, что у тебя уже стоит в другом приложении) → «Сочетание занято другой программой» и кнопки свободных вариантов. Старое сочетание продолжает работать.
- [ ] 4.5. Нажми «По умолчанию» — вернулось Ctrl + Alt + Space.
- [ ] 4.6. Внизу настроек написано «Pocket 1.0.0 · полный интерфейс» (если «облегчённый» — в сборку не попал веб, сообщи).

## 5. Запись и отмена (1 мин)
- [ ] 5.1. Ctrl+Alt+Space → напиши `еда 250к` → Enter. Появляется карточка «✓ 250 000 ₫ · Еда» с кнопками «Отменить» и «Изменить», поле очистилось, курсор в нём. «Сегодня» увеличилось на 250 000 ₫, операция в «Последних».
- [ ] 5.2. Shift+Enter в поле — перенос строки, а не отправка.
- [ ] 5.3. Нажми «Отменить» (или Ctrl+Z при пустом поле) → «Отменено …» и кнопка «Вернуть»; операция пропала из «Последних» и из веба/бота.
- [ ] 5.4. Запиши `кофе 45к` → «Изменить» → напиши `50к` → Enter: сумма исправлена на 50 000 ₫.
- [ ] 5.5. Запиши что-нибудь в Telegram-боте — через пару секунд оно появляется в «Последних» окна Pocket (или сразу при следующем открытии).
- [ ] 5.6. Выключи Wi-Fi → значок в трее становится с серой монетой, в окне «Нет связи». Напиши `такси 50к` → «Не сохранено — нет связи», текст остался в поле. Включи Wi-Fi → запись уходит сама (или по «Повторить»), дубля нет.

## 6. Полная панель и автозапуск (30 с)
- [ ] 6.1. Кнопка ⧉ в окне (или Ctrl+Shift+F, или меню трея «Полная панель») → большое окно Pocket, **без повторного входа**. Ссылки на внешние сайты открываются в браузере.
- [ ] 6.2. Закрой большое окно крестиком — Pocket остаётся в трее.
- [ ] 6.3. Перезагрузи Windows (или выйди из учётной записи и войди) → значок Pocket снова в трее, окно само не выскакивает, пароль не спрашивает. Ctrl+Alt+Space работает.
- [ ] 6.4. Настройки → сними «Запускать вместе с Windows» → после перезагрузки Pocket не стартует. Включи обратно.
- [ ] 6.5. Запусти Pocket из меню «Пуск», когда он уже запущен, — второй значок не появляется, просто открывается окно.

## 7. Выход
- [ ] 7.1. Меню трея → «Выход» — значок исчезает, Ctrl+Alt+Space больше не открывает окно.
- [ ] 7.2. *(по желанию)* Настройки → «Выйти на этом устройстве» → снова экран входа; в вебе устройство исчезло из списка.

Удаление: Параметры → Приложения → Pocket → Удалить.
