# Бенчмарк моделей разбора (AI_MODEL)

Pocket сначала разбирает фразу встроенным правиловым парсером; в LLM уходит только то, что парсер
не понял уверенно. Бенчмарк показывает, насколько хорошо выбранная модель справляется именно с
этим «трудным путём», — чтобы выбрать `AI_MODEL` для своей установки.

## Что меряется

- Харнесс: `backend/bench/` — production `LLMClient` (тот же системный промпт, JSON-схема,
  repair-повтор), **только LLM**, без правилового парсера.
- Датасет: `backend/bench/dataset.jsonl` — фразы на русском и английском с ожидаемыми интентами
  (расходы/доходы, переводы и обмены, крипта, даты, правки и отмена, вопросы, долги).
- Контекст замороженный (`backend/bench/context.py`): «сегодня», стартовые счета, категории и
  продавцы — чтобы результаты разных моделей были сравнимы.

Метрики (по каждой модели):

| Метрика | Что значит |
|---|---|
| Точность фразы (exact) | все поля всех интентов совпали и число интентов верное |
| Интент / сумма / валюта / дата / категория / счёт / цель правки | точность по отдельным полям |
| Ошибки JSON | доля ответов, не прошедших схему даже после repair-повтора |
| p50 / p95, мс | задержка ответа |
| Токены | вход / выход на фразу |

Поля сравниваются после канонизации production-валидатором (суммы из `amount_raw`, ссылки → имена).

## Как запустить на своей модели

Бенчмарк делает настоящие вызовы API и тратит токены (≈ 200 фраз на модель). Нужен файл с
`AI_BASE_URL` и `AI_API_KEY` (подойдёт ваш `.env`):

```bash
cd backend
uv run python -m bench.run --self-check                      # проверка датасета и скорера, без API
uv run python -m bench.run --env ../.env --models your-model --limit 5     # смоук
uv run python -m bench.run --env ../.env --models your-model,another-model \
    --concurrency 4 --out bench/results/summary.json
```

Результаты по каждой фразе пишутся в `backend/bench/results/` (каталог в `.gitignore`), итоговая
таблица печатается в Markdown. Параллельность больше 4 харнесс не разрешает; на 429/5xx он делает
паузу и повторяет.

Цифр конкретных моделей здесь нет намеренно: они зависят от провайдера, версии модели и даже
времени суток. Прогоните бенчмарк на том, чем пользуетесь сами.
